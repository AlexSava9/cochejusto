Espacio publicitario

¿Qué incluye el precio?

Incluye el sensor nuevo (sonda lambda) y la mano de obra. Algunos coches tienen dos o más sensores lambda. El precio puede variar según cuál de ellos haya fallado (pre-catalizador o post-catalizador).

¿Cuándo es necesario?

El sensor lambda falla cuando se enciende el testigo del motor, aumenta el consumo de combustible, el motor va irregular o el coche no supera la ITV por exceso de emisiones.

Preguntas frecuentes

¿Puedo circular con el sensor lambda averiado?

El coche puede seguir funcionando pero con mayor consumo y emisiones elevadas. A largo plazo puede dañar el catalizador, lo que supone una reparación mucho más cara. Conviene repararlo pronto.
